## 🔍 دیباگ

### مشکلات احتمالی:

#### 1. نقشه نمایش داده نمی‌شود
**علت:** API Key نامعتبر یا محدود
**راه‌حل:**
- API Key را بررسی کنید
- محدودیت‌های Domain را بردارید
- Billing را فعال کنید

#### 2. Markers نمایش داده نمی‌شوند
**علت:** آموزشگاه‌ها Lat/Lng ندارند
**راه‌حل:**
- مختصات را اضافه کنید
- یا از Google Maps iframe استفاده کنید

#### 3. Clustering کار نمی‌کند
**علت:** کتابخانه بارگذاری نشده
**راه‌حل:**
- اتصال اینترنت را بررسی کنید
- CDN را تست کنید

#### 4. View تغییر نمی‌کند
**علت:** JavaScript خطا دارد
**راه‌حل:**
- Console browser را بررسی کنید
- Cache را پاک کنید
