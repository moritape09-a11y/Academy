# راهنمای استفاده از نسخه 3.3 - پلاگین دایرکتوری آموزشی جامع

## 🎉 به نسخه جدید خوش آمدید!

این نسخه از پلاگین با قابلیت‌های پیشرفته‌تر و امکان مدیریت انواع مختلف موجودیت‌های آموزشی طراحی شده است.

---

## 🆕 امکانات جدید

### 1️⃣ سه نوع موجودیت آموزشی

حالا می‌توانید علاوه بر **آموزشگاه‌ها**، موارد زیر را هم مدیریت کنید:

- 🎓 **آموزشگاه‌ها** (Academies) - موسسات آموزش مهارت‌های حرفه‌ای
- 🏫 **مدارس** (Schools) - مدارس و موسسات تحصیلی
- 👨‍🏫 **معلمین و مربی‌ها** (Teachers) - اساتید، معلمین و مربی‌های خصوصی

### 2️⃣ فیلدهای اختصاصی برای هر نوع

#### فیلدهای مشترک (برای همه):
- شماره تماس
- ایمیل
- وب‌سایت
- اینستاگرام و تلگرام
- امتیاز (1 تا 5 ستاره)
- اولویت نمایش
- وضعیت ویژه

#### فیلدهای اختصاصی آموزشگاه و مدرسه:
- رشته‌ها و دوره‌های ارائه شده
- آدرس کامل
- سال تاسیس
- ظرفیت دانش‌آموز
- نقشه موقعیت (iframe یا مختصات)

#### فیلدهای اختصاصی معلم/مربی:
- تخصص (مثال: ریاضی، فیزیک، زبان)
- سابقه تدریس (به سال)
- مدرک تحصیلی (دیپلم تا دکتری)
- روش تدریس (حضوری، آنلاین، هیبریدی)
- شهریه ساعتی
- موسسه وابسته

### 3️⃣ سیستم دسته‌بندی پیشرفته (Taxonomies)

- **رشته‌ها**: دسته‌بندی بر اساس رشته تحصیلی (ریاضی، زبان، هنر و...)
- **نوع موسسه**: دولتی یا خصوصی (برای آموزشگاه‌ها و مدارس)
- **مقطع تحصیلی**: ابتدایی، راهنمایی، دبیرستان و... (برای مدارس و معلمین)

---

## 📋 نحوه استفاده

### افزودن موجودیت جدید

1. از منوی مدیریت وردپرس، یکی از گزینه‌های زیر را انتخاب کنید:
   - **آموزشگاه‌ها** → افزودن آموزشگاه جدید
   - **مدارس** → افزودن مدرسه جدید
   - **معلمین و مربی‌ها** → افزودن معلم/مربی جدید

2. عنوان و توضیحات را وارد کنید

3. تصویر شاخص را آپلود کنید (توصیه می‌شود)

4. در بخش **اطلاعات** (متاباکس)، فیلدهای مورد نیاز را پر کنید

5. دسته‌بندی‌های مناسب را انتخاب کنید

6. روی **انتشار** کلیک کنید

## 🎨 نمایش در سایت با Shortcode

### شورت‌کد اصلی: `[edu_directory]`

#### مثال‌های استفاده:

```shortcode
// نمایش همه موارد (آموزشگاه، مدرسه، معلم)
[edu_directory type="all" cols="3" per_page="9"]

// فقط آموزشگاه‌ها
[edu_directory type="academy" cols="4" per_page="12"]

// فقط مدارس
[edu_directory type="school" cols="3"]

// فقط معلمین و مربی‌ها
[edu_directory type="teacher" cols="4"]

// ترکیب چند نوع (مدرسه و آموزشگاه)
[edu_directory type="school,academy" cols="3"]
```

### پارامترهای شورت‌کد:

| پارامتر | توضیح | مقدار پیش‌فرض | مثال |
|---------|-------|---------------|------|
| `type` | نوع موجودیت | `academy` | `academy`, `school`, `teacher`, `all` |
| `cols` | تعداد ستون‌ها | `3` | `1`, `2`, `3`, `4` |
| `per_page` | تعداد آیتم در هر صفحه | `9` | هر عدد مثبت |

## 🎯 ویژگی‌های طراحی جدید

### کارت‌های متمایز
- هر نوع موجودیت با **رنگ و آیکون مخصوص** نمایش داده می‌شود:
  - 🎓 آموزشگاه: **زرد** (#ffc400)
  - 🏫 مدرسه: **آبی** (#2196F3)
  - 👨‍🏫 معلم: **سبز** (#4CAF50)

### انیمیشن‌های جذاب
- انیمیشن Fade In برای ظاهر شدن کارت‌ها
- انیمیشن Hover با افکت Float
- انیمیشن Zoom برای تصاویر

### طراحی ریسپانسیو
- نمایش عالی در موبایل، تبلت و دسکتاپ
- تنظیم خودکار تعداد ستون‌ها بر اساس اندازه صفحه

### فیلترهای پیشرفته
- جستجوی متنی
- فیلتر بر اساس رشته
- فیلتر بر اساس امتیاز
- فیلتر بر اساس نوع موجودیت (در حالت `all`)

## 💡 نکات مهم

### 1. سازگاری با نسخه قبلی
تمام آموزشگاه‌های قبلی شما حفظ می‌شوند و به صورت خودکار در سیستم جدید کار می‌کنند.

### 2. شورت‌کد قدیمی
شورت‌کد قبلی `[academy_directory_pro]` همچنان کار می‌کند ولی توصیه می‌شود از `[edu_directory]` استفاده کنید.

### 3. تصاویر
- اندازه پیشنهادی: **800x600 پیکسل**
- فرمت: JPG یا PNG
- اگر تصویری آپلود نکنید، آیکون پیش‌فرض زیبایی نمایش داده می‌شود

### 4. SEO
پلاگین با Schema.org سازگار است و به SEO سایت شما کمک می‌کند.

## 🎨 سفارشی‌سازی CSS

می‌توانید استایل‌های زیر را در فایل CSS قالب خود override کنید:

```css
/* تغییر رنگ آموزشگاه */
:root {
  --adp-yellow: #your-color;
}

/* تغییر رنگ مدرسه */
:root {
  --adp-blue: #your-color;
}

/* تغییر رنگ معلم */
:root {
  --adp-green: #your-color;
}

/* تغییر شعاع گوشه‌ها */
:root {
  --adp-radius: 15px;
}
```
