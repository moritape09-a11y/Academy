## 🎨 ویژگی‌های طراحی

### کارت‌های موجودیت
1. **بج رنگی**: شناسایی سریع نوع موجودیت
2. **آیکون اختصاصی**: 
   - 🎓 آموزشگاه
   - 🏫 مدرسه
   - 👨‍🏫 معلم
3. **رنگ‌بندی هوشمند**: هر نوع با رنگ مخصوص
4. **انیمیشن Hover**: افکت Float + Zoom
5. **اطلاعات داینامیک**: نمایش فیلدهای مهم

### فیلترها
1. **انتخاب نوع**: دراپ‌داون با ایموجی
2. **جستجو**: با placeholder هوشمند
3. **رشته**: فیلتر بر اساس تخصص
4. **امتیاز**: 1 تا 5 ستاره
5. **دکمه‌ها**: با آیکون و انیمیشن

## 🔧 معماری کد

### اصول طراحی:
1. **Separation of Concerns**: هر کلاس مسئولیت خاص خود را دارد
2. **DRY (Don't Repeat Yourself)**: استفاده از توابع کمکی
3. **Extensibility**: آسانی افزودن نوع جدید
4. **Maintainability**: کد تمیز و مستندسازی شده
5. **Security**: اعتبارسنجی و Sanitization کامل

### ساختار:
```
ADP_CPT → مدیریت Post Types و Taxonomies
ADP_Metabox → مدیریت فیلدها و ذخیره‌سازی
ADP_Shortcode → نمایش در فرانت‌اند
ADP_Helpers → توابع کمکی و رندر
```

## 🚀 نحوه استفاده

### برای توسعه‌دهندگان:

#### افزودن نوع جدید:
```php
// در adp-cpt.php
private static $entity_types = array(
    'your_type' => array(
        'singular' => 'عنوان',
        'plural'   => 'عنوان جمع',
        'icon'     => 'dashicons-icon',
        'slug'     => 'url-slug',
    ),
);
```

#### افزودن فیلد جدید:
```php
// در adp-metabox.php
private static $your_fields = array(
    'field_key' => array(
        'label' => 'برچسب',
        'type'  => 'text',
        'icon'  => 'fa-icon',
    ),
);
```

#### سفارشی‌سازی رنگ:
```css
:root {
  --adp-yellow: #your-color;
}
```
