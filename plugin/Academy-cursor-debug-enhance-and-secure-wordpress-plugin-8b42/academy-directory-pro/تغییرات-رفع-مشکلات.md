## 🐛 مشکلات رفع شده

### مشکل 1: فیلتر بر اساس ستاره کار نمی‌کرد ⭐

**شرح مشکل:**  
زمانی که کاربر سعی می‌کرد بر اساس امتیاز (ستاره) جستجو کند، همه آموزشگاه‌ها "یافت نشد" نمایش داده می‌شد.

**علت:**  
در به‌روزرسانی قبلی، meta key را از `_adp_rating` به `_adp_average_rating` تغییر دادیم، اما:
- داده‌ها با `_adp_rating` ذخیره می‌شوند
- `_adp_average_rating` فقط برای نظرات (comments) محاسبه می‌شود
- پس فیلتر دنبال کلید اشتباه می‌گشت!

**راه‌حل:**
✅ بازگردانی meta key به `_adp_rating` در:
- `includes/adp-ajax.php` (فیلتر AJAX)
- `includes/adp-shortcode.php` (فیلتر معمولی)

**فایل‌های تغییر یافته:**
```php
// includes/adp-ajax.php - خط 50
$meta_query[] = array( 
    'key' => '_adp_rating',  // قبلاً: _adp_average_rating
    'value' => $min_rating, 
    'type' => 'NUMERIC', 
    'compare' => '>=' 
);

// includes/adp-shortcode.php - خط 31
$meta_query[] = array( 
    'key' => '_adp_rating',  // قبلاً: _adp_average_rating
    'value' => $min_rating, 
    'type' => 'NUMERIC', 
    'compare' => '>=' 
);
```

**نتیجه:**  
✅ فیلتر ستاره حالا درست کار می‌کند  
✅ آموزشگاه‌ها بر اساس امتیاز صحیح فیلتر می‌شوند

### مشکل 2: نقشه گوگل مپ نمایش داده نمی‌شد 🗺️

**شرح مشکل:**  
زمانی که کاربر کد iframe گوگل مپس را در فیلد "کد HTML نقشه" وارد می‌کرد، نقشه در صفحه آموزشگاه نمایش داده نمی‌شد.

**علت:**
1. CSS مناسب برای نمایش responsive iframe وجود نداشت
2. CSP headers تمام domainهای گوگل مپس را مجاز نکرده بود
3. ممکن بود `wp_kses_post()` برخی attributeهای iframe را حذف کند

**راه‌حل:**

#### 1️⃣ بهبود HTML Output
✅ استفاده از `wp_kses()` با allowlist کامل iframe:
```php
// includes/adp-helpers.php - خط 138-149
$allowed_iframe = array( 
    'iframe' => array( 
        'src' => true, 
        'width' => true, 
        'height' => true, 
        'style' => true, 
        'allowfullscreen' => true, 
        'loading' => true, 
        'referrerpolicy' => true, 
        'frameborder' => true 
    ) 
);
$out .= '<div class="adp-embed adp-embed-single">' . wp_kses( $embed, $allowed_iframe ) . '</div>';
```

#### 2️⃣ بهبود CSS برای Responsive Design
✅ اضافه شدن استایل‌های responsive به:
- `assets/css/style.css` (تم زرد)
- `assets/css/blue-theme.css` (تم آبی)

```css
/* Map embed - responsive iframe container */
.adp-embed-single {
    position: relative;
    width: 100%;
    padding-bottom: 56.25%; /* 16:9 aspect ratio */
    height: 0;
    overflow: hidden;
    border-radius: var(--adp-radius);
    box-shadow: var(--adp-shadow);
    margin-top: 15px;
}

.adp-embed-single iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    border: 0;
    border-radius: var(--adp-radius);
}
```

**ویژگی‌های CSS جدید:**
- 📱 Responsive (16:9 aspect ratio)
- 🎨 Border radius زیبا
- 💎 Shadow برای جلوه بهتر
- 📏 Full width در همه اندازه‌های صفحه

#### 3️⃣ به‌روزرسانی Content Security Policy
✅ اضافه شدن domainهای گوگل مپس به CSP:
```php
// includes/adp-core.php - خط 139-150
"script-src ... https://maps.gstatic.com ...",
"img-src ... https://maps.googleapis.com https://maps.gstatic.com",
"connect-src ... https://maps.gstatic.com",
"frame-src ... https://maps.googleapis.com",
```

**نتیجه:**  
✅ iframe گوگل مپس حالا به‌درستی نمایش داده می‌شود  
✅ نقشه در تمام اندازه‌های صفحه responsive است  
✅ CSP headers اجازه بارگذاری نقشه را می‌دهند  
✅ طراحی زیبا و حرفه‌ای

## 📝 نحوه استفاده

### برای اضافه کردن نقشه:

1. **به پنل مدیریت وردپرس** بروید
2. **آموزشگاه‌ها** → ویرایش یا ایجاد آموزشگاه
3. در فیلد **"کد HTML نقشه"**، کد iframe گوگل مپس را paste کنید
4. **ذخیره** کنید

**مثال کد iframe:**
```html
<iframe src="https://www.google.com/maps/embed?pb=!1m14!1m8!1m3!1d3240.3110541204837!2d51.4452912!3d35.6939624!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x3f8e03b854cd8129%3A0x6005b0b094936344!2z2KLYqNmE24zZhdmIINiu2YjYsdi024zYrw!5e0!3m2!1sfa!2s!4v1760133072380!5m2!1sfa!2s" width="600" height="450" style="border:0;" allowfullscreen="" loading="lazy" referrerpolicy="no-referrer-when-downgrade"></iframe>
```

**نکات مهم:**
- ✅ می‌توانید کل کد iframe را کپی-پیست کنید
- ✅ نیازی به حذف attributeها نیست
- ✅ width و height اهمیتی ندارند (responsive می‌شود)
- ✅ نقشه به‌صورت خودکار responsive می‌شود
