### مشکل 3: دکمه بازنشانی → Reload ✅
**قبل:** فقط فیلترها را خالی می‌کرد  
**حالا:** صفحه را reload می‌کند

**تغییر:**
```javascript
// assets/js/script.js

// قبل:
$('#adp-reset').on('click', function() {
    form.find('input[type=text]').val('');
    form.find('select').val('0');
    form.trigger('submit');
});

// حالا:
$('#adp-reset').on('click', function() {
    window.location.href = window.location.pathname;
});
```

**نتیجه:**
- ✅ کلیک روی "بازنشانی" = صفحه reload می‌شود
- ✅ تمام فیلترها پاک می‌شوند
- ✅ به حالت اولیه برمی‌گردد

### مشکل 4: قاطی شدن Grid و List بعد از Search ✅

**علت:** View فعلی در AJAX request ارسال نمی‌شد

**راه‌حل:**
```javascript
// assets/js/script.js

form.on('submit', function(e) {
    // دریافت View فعلی از Cookie
    var currentView = getCookie('adp_view') || 'grid';
    
    var data = {
        action: 'adp_filter',
        nonce: adp_ajax.nonce,
        view: currentView,  // ✅ ارسال view فعلی
        cols: resultsWrapper.data('cols') || 3
        // ...
    };
});
```

**نتیجه:**
- ✅ بعد از search، View حفظ می‌شود
- ✅ Grid → Grid باقی می‌ماند
- ✅ List → List باقی می‌ماند
